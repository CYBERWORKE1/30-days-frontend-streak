Day 2 – Responsive Navigation Bar

On Day 2 of my 30 Days Frontend Streak, I built a responsive navigation bar using pure HTML, CSS, and JavaScript.

The goal of this project was to understand how real-world navigation menus work across different screen sizes and devices.

I chose to start from scratch instead of using frameworks or libraries because building the fundamentals manually helps me understand layout, responsiveness, and JavaScript logic more deeply.

This approach strengthens my core frontend skills and prepares me to work confidently with modern frameworks like React in later projects.
